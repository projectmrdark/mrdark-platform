## Getting Started

### Sign In

1. Visit the Mr.Dark platform homepage
2. Click "Sign In to Get Started"
3. Authenticate using your Manus account
4. You'll be redirected to the chat interface

### First Conversation

1. Click "Start Chatting" from the homepage
2. Type your message in the input field
3. Press Enter or click the Send button
4. Watch as the AI processes your request and responds

## Using the Chat Interface

### Sending Messages

1. Type your message in the input field at the bottom
2. Press Enter or click the Send button
3. Your message appears on the right side
4. AI responses appear on the left side with markdown formatting

### Message Features

- **Markdown Rendering**: Responses support full markdown including:
  - **Bold** and *italic* text
  - Code blocks with syntax highlighting
  - Lists and tables
  - Links and images

- **Code Blocks**: Automatically highlighted based on language
- **Streaming Responses**: See the AI's response as it's generated

### Keyboard Shortcuts

- **Enter**: Send message
- **Shift + Enter**: New line in message
- **Esc**: Cancel current operation (when available)

## Managing Sessions

### Creating Sessions

1. Click "New Session" from the Sessions page
2. Or start typing in the chat interface
3. Sessions are automatically created with your first message

### Viewing Sessions

1. Click "Sessions" in the header
2. See all your past conversations
3. Each session shows:
   - Title (auto-generated from first message)
   - Creation date
   - Model used
   - Execution mode (Sandbox/Local)
   - Status (Active/Archived)

### Session Actions

- **Open**: Click on a session card to continue the conversation
- **Delete**: Click the trash icon to permanently delete a session

## Troubleshooting

### Common Issues

**Problem**: AI not responding
- **Solution**: Check your internet connection, refresh the page

**Problem**: Tool execution failed
- **Solution**: Check the error message in the execution viewer, try rephrasing your request

**Problem**: Can't sign in
- **Solution**: Ensure you have a valid Manus account, clear browser cache

**Problem**: Session not loading
- **Solution**: Refresh the page, check if the session still exists

### Error Messages

- **"Session not found"**: The session may have been deleted
- **"Tool execution failed"**: The tool encountered an error, check parameters
- **"Quota exceeded"**: You've reached your usage limit, upgrade or wait for reset

### Getting Help

If you encounter issues:
1. Check this documentation
2. Review error messages in the execution viewer
3. Contact support at https://help.manus.im
